# Udaya Shrestha — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `styles.css` — design, responsive layout, animations
- `script.js` — scroll reveal, mobile menu, cursor glow, dynamic year

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Replace the LinkedIn and GitHub placeholder links with your profiles.
3. Add a profile photo later if you want one.
4. Add your real projects to the Projects section.

## Local preview
Open `index.html` in a browser.

## Deployment
The project is suitable for GitHub + Cloudflare Pages and does not require a paid server.
